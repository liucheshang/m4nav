# m4nav —— M4 蓝牙手环导航显示（Android 端）

把高德导航指令直接写进 10 元公模 M4 手环（型号 P19 / TJDP，屏 80×160）的消息弹窗。

## 它做什么

- 监听高德通知（"300米后右转"），解析方向与距离
- 用 GPS 每 50 米做倒计时：`↑500 → ↑250 → ↑200→ → ↑100→ → ↑50→ → →`
- 按实测协议组帧写 BLE 特征 `00002d01`（AB + 总长 + 17 + 08 01 01 + 正文 + CRC8）

## 三种用法

1. **全自动**：授权通知使用权 + 定位 → 开着高德导航骑行，全程不用碰手机
2. **手动测试**：App 里输入"300米后右转"，点推送
3. **外部喂数据**（可选）：App 开了本地入口 `http://127.0.0.1:8766/nav`，
   可以 POST `{"text":"300米后右转","lat":32.99,"lon":112.53}`，
   也可以只 POST `{"lat":32.99,"lon":112.53}` 当定位心跳。

## 怎么拿到 APK（不需要装 Android Studio）

1. 建一个 GitHub 仓库，把本目录全部文件上传（含 `.github/workflows/build.yml`）
2. 仓库页 → **Actions** → 左侧 `Build APK` → 右上 `Run workflow`
3. 等 3~8 分钟（首次要下 Gradle 依赖）
4. 该次运行页面底部 → **Artifacts** → 下载 `m4nav-debug-apk`
5. 解压得到 `app-debug.apk`，传到手机安装（需允许"安装未知来源应用"）

debug 包自动用 GitHub runner 上的 debug keystore 签名，**不需要你配证书**。

## 手机端必开

- 蓝牙（附近设备）、精确位置（含后台）、通知使用权
- 应用电池策略设"不受限制"，并加进自启动白名单（国产 ROM 必须，否则息屏被杀）

## 协议要点（照实测结论，改之前先看交付说明）

| 项 | 值 |
|---|---|
| 服务 | `000018d0-0000-1000-8000-00805f9b34fb` |
| 写特征 | `00002d01-…`（WriteWithoutResponse） |
| 帧 | `AB + 总长 + 17 + icon + 01 + 01 + 正文 + CRC8` |
| icon | 只允许 `0x08`（聊天）/ `0x01`（来电） |
| 正文 | ≤13 字节，**片总数必须是 1**，分片会被固件静默丢弃 |
| 单次写入 | ≤20 字节 |

## 已知限制

- 一条消息 = 一帧 = 一行；手环消息列表是**最近 3 条滚动替换**，新推送会顶掉旧的
- 可用字形只有 `← → ↑ ↓ ★ ☆` 与 ASCII/中文；`↩ ↻ ↗ ↱ ➡ ▶ ●` 实测空白
- 本工程未经本地编译验证，首次 CI 若报错，按日志修依赖版本即可
